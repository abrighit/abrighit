# Meu Segundo Cérebro — KeepOS

## 1. Tema e objetivo

**Objetivo original:** criar um guia para configurar o KeepOS rapidamente.

Este projeto tem como finalidade organizar informações e orientações para facilitar a configuração e a utilização do sistema operacional KeepOS.

## 2. Fontes utilizadas

| Fonte | Tipo | Justificativa |
|---|---|---|
| ASUS Brasil — KeepOS | Site institucional | Informações da própria fabricante sobre o sistema. |
| Debian — Manuais de usuários | Documentação técnica | Referência oficial para conhecimentos sobre o ambiente Linux. |
| Como mudar o idioma do Linux para português | Vídeo tutorial | Demonstração prática de configuração do idioma. |
| Como usar o Keep OS? Review completo no ASUS Vivobook Go 15 | Vídeo | Apresentação prática do sistema em um notebook ASUS. |
| O que não te contam sobre o Keep-OS do Vivobook GO 15 | Vídeo | Relato complementar sobre o uso do sistema. |

### Links das fontes

- [ASUS Brasil — KeepOS](https://www.asus.com/br/content/asus-keepos/)
- [Manuais Debian](https://www.debian.org/doc/user-manuals.pt.html)

Os materiais foram selecionados considerando sua procedência e relevância. A documentação da ASUS e do Debian é utilizada como referência técnica, enquanto os vídeos complementam as informações com demonstrações práticas.
